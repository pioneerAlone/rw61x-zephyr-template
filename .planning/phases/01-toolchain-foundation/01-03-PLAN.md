  <how-to-verify>
**Prerequisites:** RW612 hardware connected, J-Link probe connected, west workspace initialized with `west update` and `west blobs fetch hal_nxp` completed.

**Step 1 — Build:**
```bash
cd /path/to/workspace  # workspace root (parent of app/)
west build -b frdm_rw612 app/
```
Expected: Build completes with no errors. `build/zephyr/zephyr.elf` exists.

**Step 2 — Flash:**
```bash
west flash --runner jlink
```
Expected: J-Link connects, firmware flashed, device resets.

**Step 3 — Verify UART output:**
Open serial terminal at 115200 8N1 on the board's USB-serial port.
Expected output (something like):
```
[00:00:00.000,000] <inf> main: RW61x Zephyr template v1.0
[00:00:00.000,000] <inf> main: Board: frdm_rw612
```

**Step 4 — Verify J-Link debug in VS Code:**
1. Open `app/` folder in VS Code
2. Install recommended extensions when prompted (especially cortex-debug)
3. Press F5 (or Run → Start Debugging → "Debug (J-Link)")
4. Expected: Build runs, J-Link connects, execution stops at `main()`
5. Set a breakpoint on the `LOG_INF` line, press Continue
6. Expected: Breakpoint hits, you can inspect variables

**If J-Link device string fails:**
Run `JLinkExe -device ?` and search for RW612. Update `"device"` in `.vscode/launch.json` to the correct string (e.g., `MIMXRW612`).

**If blobs missing:**
Run `west blobs list hal_nxp` — if any show as missing, run `west blobs fetch hal_nxp`.
