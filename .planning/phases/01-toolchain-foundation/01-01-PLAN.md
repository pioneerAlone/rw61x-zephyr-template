}

Create `app/CMakeLists.txt` using the minimal Zephyr pattern. Do NOT use `zephyr_library()` (deprecated for app code). Use `target_sources(app PRIVATE ...)`. Include a comment about the EXTRA_CONF_FILE pattern for fragment loading.

Create `app/src/main.c` with:
- `#include <zephyr/kernel.h>` and `#include <zephyr/logging/log.h>` (use namespaced paths — old `#include <kernel.h>` is deprecated)
- `LOG_MODULE_REGISTER(main, LOG_LEVEL_INF)` — registers this file's log module
- `int main(void)` (not `void main()` — Zephyr 3.1+ requires int return)
- Log messages: board name, template version, a "Hello World" style startup message
- Return 0

Add inline comments explaining each section for template users.
