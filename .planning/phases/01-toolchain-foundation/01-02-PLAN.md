Create `app/.vscode/launch.json` with a cortex-debug J-Link configuration for RW612:

- `"servertype": "jlink"` — locked decision, do not use openocd or pyocd
- `"device": "RW612"` — add a comment: "If J-Link fails to connect, run `JLinkExe -device ?` to find the exact device string (may be MIMXRW612)"
- `"interface": "swd"` — SWD is standard for Cortex-M33
- `"executable"`: point to `${workspaceFolder}/build/zephyr/zephyr.elf`
- `"preLaunchTask": "west build"` — triggers build before debug session
- `"runToEntryPoint": "main"` — stops at main() on launch
- `"svdFile"`: set to `${workspaceFolder}/../zephyr/dts/arm/nxp/rw612.svd` with a comment: "Remove this line if the SVD file doesn't exist after west update"
- `"showDevDebugOutput": "none"` — reduces noise in debug console

Add a second configuration variant "Attach (J-Link)" with `"request": "attach"` for attaching to a running target without reflashing.

Create `app/.vscode/tasks.json` with these tasks:
1. `"west build"` — `west build -b frdm_rw612` with `problemMatcher: ["$gcc"]`, marked as default build task. Add a comment showing how to build with extra conf: `west build -b frdm_rw612 -- -DEXTRA_CONF_FILE=conf/debug.conf`

3. `"west flash"` — `west flash --runner jlink`, dependsOn: `"west build"`
